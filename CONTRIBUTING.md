# Contributing Guidelines

Thank you for your interest in contributing! We welcome bug reports, feature requests, documentation improvements, and pull requests.

## Ground Rules

- **Code of Conduct**: Treat everyone with respect. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
- **Security Disclosures**: Report security vulnerabilities privately through [GitHub](https://github.com/rmrashahriar) or directly to `@rmrashahriar`.
- **Focused Changes**: Keep pull requests focused on a single topic, bug fix, or feature.

## Pull Request Workflow

1. **Fork or Branch**: Create a feature branch with a descriptive name (e.g., `feature/xyz` or `fix/issue-123`).
2. **Make Changes**: Adhere to existing code formatting and styling conventions.
3. **Test**: Verify that your changes run cleanly and do not break existing functionality.
4. **Commit Messages**: Write clear, conventional commit messages (e.g., `feat: ...`, `fix: ...`, `docs: ...`).
5. **Submit**: Open a Pull Request with a summary of changes and testing notes.
